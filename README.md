## ▶️ Como executar o projeto

**1. Instalar as dependências**

```bash
npm install
```

**2. Iniciar o servidor de desenvolvimento**

```bash
npm run dev
```

**3. Abrir no navegador**

Acesse o endereço local informado pelo Vite no terminal.
